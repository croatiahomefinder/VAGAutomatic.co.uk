DQ500 controller identification

DQ500 Bosch or Continental? Read the controller label, not just the gearbox code.

DQ500 gearboxes appear with more than one controller family. The gearbox prefix alone is not reliable enough for a postal repair decision. Before you send a unit for P1735, P1736, P0805 or another electronics fault, identify the controller from the label and hardware number.

Send us a label photoCheck fault code
Fast rule

Bosch usually carries a 0 260 550… / 0260550… hardware number. Continental commonly carries 5WP… or A2C… numbering.

These are identification clues, not an exhaustive part-number catalogue. If the label is unclear, send a clear photo before posting anything.

Label clues

Two controller families, different repair routes.

The same customer description such as “only even gears” can sit on different hardware. We identify the electronics first, then match the repair.

Bosch DQ500

Look for Bosch-style hardware numbering

  • Numbers beginning 0 260 550… or compact form 0260550…
  • VAG numbers can include examples such as 0DE 927 711 or 0GC 927 711 revisions
  • P1735 / P1736 / P0805 is our main supported fixed-price Bosch fault family
Bosch repair page
Continental DQ500

Look for Continental 5WP or A2C numbering

  • Hardware numbers commonly use 5WP… or A2C… formats
  • Examples seen across the family include 5WP2500x and A2C39… numbering
  • Continental has a broader electronics fault range, so several codes are test-first rather than automatically fixed-price
Continental repair page

Do not identify it from 0BH, 0BT, 0DL or 0DV alone.

Those gearbox prefixes are useful context, but they do not reliably tell you whether the controller in front of you is Bosch or Continental. For a mail-in electronics repair, the controller label and hardware number are the deciding evidence.

1. Photograph the labelMake sure the controller maker, VAG number and hardware number are readable.
2. Photograph the connector sideThis helps when the printed label is damaged or a previous unit has been fitted.
3. Send the complete scanDo not send only one fault code. Companion codes often change the diagnosis route.
4. We confirm before you postIf the controller family is uncertain, we would rather identify it first than receive the wrong unit.
