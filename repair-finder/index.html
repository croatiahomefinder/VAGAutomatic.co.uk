Why wording changes

One fault can have several names depending on the diagnostic tool.

Google searches are often copied straight from a scanner. That is why the site includes the P-code, compact code form, VAG number and the natural-language fault description where we can identify them confidently.

P1735 / P173500 / 10666

Often shown as clutch 1 position sender / sensor electrical fault on supported DQ381 or DQ500 controllers.

P1736 / P173600 / 10668

Often shown as clutch 2 position sender / sensor electrical fault.

P189C / 006300

DQ200 insufficient hydraulic pressure build-up wording.

P17BF

DQ200 hydraulic pump overload / protection wording associated with pressure-loss problems.

Only even / odd gears

A useful real-world clue for a fault affecting one clutch path on DQ381/DQ500 applications.

P0C29

Auxiliary hydraulic pump fault. This is a vehicle/gearbox-level diagnosis route, not a TCM-only postal repair.

What the result means

Green, amber or red.

✓ Green

Supported fixed-price fault. The price, turnaround, warranty and what to send are published on the repair page.

! Amber

Potentially repairable, but the code is not specific enough to sell a fixed repair without seeing the full scan or testing the unit.

✕ Red

Do not send the TCM only. The fault points toward vehicle wiring, gearbox mechanics, an auxiliary hydraulic system or another diagnosis that needs more than a postal controller repair.
