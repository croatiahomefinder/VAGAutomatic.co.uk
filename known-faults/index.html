Known DSG Fault Library

Search the fault code exactly as your scanner shows it.

ODIS, VCDS, Autel, Launch, Topdon and generic tools often describe the same transmission fault differently. This library connects the code, VAG number and real-world symptom to the route we actually recommend: fixed-price repair, free test first, or vehicle/gearbox diagnosis.

How to use this page

Green is fixed-price. Amber means test first. Red means do not blindly post the TCM.

That distinction matters. A fault code is evidence, not permission to guess. We would rather turn away the wrong postal repair than charge you for a controller that was never the cause.
