Diagnosis-led TCM faults

Faults we want to see before you buy a repair.

Not every controller code belongs in a green fixed-price box. These are useful search terms and real TCM fault families, but we want the complete scan and controller label first.

DQ200 selector and sensor faults

P173A to P173D, input-speed and clutch-travel fault families can be controller, sensor/magnet or mechanical problems. Free test first.

Check DQ200 codes →

DQ250 / 02E / 0D9

No-comms, internal controller and solenoid-electrical faults can be board-side, while P0716/P1740 often points elsewhere. We do not publish a code-only fixed price yet.

Check DQ250 codes →

Continental DQ500 electronics

P0607, speed-signal and P/N signal faults can be repairable, but they are test-first rather than automatically the same service as P1735/P1736.
