Symptoms

Does this sound like your car?

  • Only odd or only even gears available
  • Reverse, 2nd, 4th and 6th work while the other gear set is lost
  • Gearbox emergency mode
  • Fault may temporarily clear after an ignition restart
  • P1735 or P1736 stored in the transmission controller
Diagnostic wording

Codes and descriptions we recognise.

P1735 / P173500 / VAG 10666Position sender for clutch 1, electrical fault. Generic tools may phrase this as clutch 1 position sensor electrical malfunction.
P1736 / P173600 / VAG 10668Position sender for clutch 2, electrical fault. Generic tools may phrase this as clutch 2 position sensor electrical malfunction.
P0805Clutch position sensor circuit. This generic description needs controller identification before repair.

ODIS, VCDS, Autel, Launch, Topdon and other scanners can phrase the same manufacturer fault differently. We match the DTC, VAG symptom number where available, controller hardware and fault meaning rather than one exact sentence.
